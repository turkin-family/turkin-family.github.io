## 🌟 1. О проекте

Данный проект представляет собой фундаментальное научно-генеалогическое исследование и мультимедийное интерактивное веб-приложение, объединяющее:
1. **Прямую непрерывную мужскую линию Туркиных** от древнейшего прародителя **Турки малого** (1490 г., грамота великого князя Ивана III) через Смутное время (Никита Туркин, 1608 г., писцовая книга Василия Шуйского), приказного человека Афанасия Туркина (1646 г.), династию священно-церковнослужителей Введенской и Христорождественской церквей XVII–XVIII вв. до наших дней;
2. **Северные родственные роды Вычегодского края**: Летовы, Ярановы, Сизевы, Шуктомовы, Зиновьевы, Поздеевы, Каракчиевы, Кызъюровы, Полещиковы, Пасынковы, Кругляковы, Айбабины, Шилины, Сюткины, Шехонины;
3. **Материнскую тайскую линию** (Таиланд: провинция Чумпхон, Бангкок — роды Питак, Памайтонг, Чамнианкан).

Исследование опирается на строгую источниковую базу: оцифрованные первоисточники из **РГАДА**, **ГАВО**, **ВЦА**, **НАРК**, **ЦАМО РФ**, трёхтомную краеведческую серию **«Усть-Вымское родословие»** (Л. А. Молодцова, В. А. Гусева, Л. В. Ванеева), базу данных духовенства **parishes.ru** и публикации летописных сводов на **vostlit.info**.

## ⚡ 3. Быстрый старт на локальном компьютере

### Запуск веб-сервера (одной командой):
```bash
python3 serve.py
```
или в Linux/macOS:
```bash
./start_server.sh
```

- Сервер запустится на **`http://localhost:8080/`** и автоматически откроет страницу в браузере.
- Для завершения работы нажмите `Ctrl + C`.

### Сборка и проверка целостности проекта:
```bash
python3 build.py
```
Скрипт автоматически проверит реляционную целостность базы данных (100% ссылок), отсутствие геометрических коллизий в Smart-Layout, пересоберёт файлы `index.html`, `tree.html`, `родословная.html` и обновит файл GEDCOM 5.5.1.

## 📁 4. Организация каталогов

- **`index.html`** / **`tree.html`** / **`родословная.html`** — интерактивное SPA-приложение с 7 вкладками: «Древо», «Поколения», «Таблица», «Архив документов (71)», «Места и роды», «Источники», «Статистика».
- **`data/`** — реляционная СУБД проекта на чистом JSON (`persons.json`, `families.json`, `sources.json`, `evidence.json`, `calibrated_coords.json`).
- **`архив_сканы_первоисточников/`** — 71 оцифрованный документ высокого разрешения (акты 1490 г., писцовые книги 1608 и 1678 гг., ревизии 1748 и 1858 гг., метрики).
- **`архив_сканы_цамо/`** — наградные листы и фронтовые приказы периода Великой Отечественной войны.
- **`книги_родословия/`** — обложки 3 томов краеведческой серии «Усть-Вымское родословие».
- **`pdf_документы/`** — фундаментальные издания, переписные книги и архивные досье в PDF.
- **`docs/`** — научные отчеты, расшифровки архивных дел, списки духовенства и методология.
  - **`docs/raw_sources/`** — оригиналы фотографий рукописного древа и служебные дампы.
- **`build.py`** — единый мастер-скрипт сборки и проверки.
- **`serve.py`** / **`start_server.sh`** — локальный HTTP-сервер.
- **`DEPLOY.md`** — детальное руководство по деплою (GitHub Pages, Vercel, Netlify, Nginx, Docker).
