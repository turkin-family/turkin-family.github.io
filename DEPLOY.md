# 🚀 Руководство по развёртыванию и деплою: Генеалогический проект «Туркины»

Данный проект представляет собой полностью автономное, высокопроизводительное статическое веб-приложение (Single Page Application без внешних серверных зависимостей) с реляционной базой данных в JSON-формате, интерактивным древом на 20 поколений, 332 персоны, 118 семей и оцифрованным архивом из 100 первоисточников.

## 💻 1. Локальный запуск (Local Development)

### Вариант А: Одной командой через Python (рекомендуется)
```bash
python3 serve.py
```
или в Linux/macOS:
```bash
./start_server.sh
```

- Сервер автоматически выберет порт `8080` (если он занят — найдёт свободный).
- Автоматически откроет браузер по адресу: **`http://localhost:8080/`**.
- Поддерживает правильные заголовки UTF-8, кэш-контроль и стриминг PDF-файлов.
- Для остановки сервера нажмите `Ctrl + C`.

Дополнительные параметры:
```bash
python3 serve.py --port 3000          # Запуск на определенном порту
python3 serve.py --no-browser         # Без автоматического открытия вкладки браузера
```

### Вариант Б: Стандартный модуль Python
```bash
python3 -m http.server 8080
```

## 🔨 2. Сборка и валидация проекта

Перед каждым деплоем или после внесения новых персоналий/документов запустите мастер-скрипт сборки:

```bash
python3 build.py
```

Мастер-скрипт автоматически производит полный цикл проверок:
1. **`data_manager.validate_integrity()`**: проверяет 100% ссылок между персонами, семьями, документами и цитатами;
2. **`layout_engine.validate_layout()`**: вычисляет пространственную геометрию карточек и гарантирует **0 наложений** ($\Delta Y \ge 85\text{px}$);
3. **`build_genealogy.export_gedcom()`**: генерирует файл `rodoslovnaya_turkin.ged` в международном стандарте GEDCOM 5.5.1;
4. **`generate_final_tree.py`**: пересобирает статические страницы `index.html`, `tree.html` и `родословная.html`.

## 🌐 3. Варианты деплоя в сеть Интернет

Так как проект является полностью статическим сайтом с относительными путями (`relative paths`), он разворачивается на любом хостинге без настройки бэкенда или СУБД.

---

### Вариант 1: GitHub Pages (Бесплатно, 2 минуты)

1. Инициализируйте Git-репозиторий (если ещё не создан):
   ```bash
   git init
   git add .
   git commit -m "Initial commit of genealogy tree"
   ```
2. Создайте репозиторий на [GitHub](https://github.com/new) (например, `rodoslovnaya-turkin`).
3. Привяжите удалённый репозиторий и отправьте код:
   ```bash
   git remote add origin git@github.com:turkin-family/turkin-family.github.io.git
   git branch -M main
   git push -u origin main
   ```
4. В настройках репозитория на GitHub:
   - Перейдите в **Settings** ➔ **Pages**;
   - В блоке **Build and deployment** выберите источник: **Deploy from a branch**;
   - В выпадающем списке выберите ветку **`main`** и папку **`/ (root)`**;
   - Нажмите **Save**.
5. Через 1 минуту проект будет доступен по ссылке:
   `https://turkin-family.github.io/`

> [!TIP]
> Поскольку файл точки входа называется `index.html`, GitHub Pages сразу откроет интерактивное древо по корневому URL.

---

### Вариант 2: Vercel / Netlify / Cloudflare Pages

1. Зарегистрируйтесь на [Vercel](https://vercel.com/) или [Netlify](https://www.netlify.com/);
2. Нажмите **Add New Project** и импортируйте ваш GitHub-репозиторий;
3. Настройки проекта:
   - **Framework Preset**: `Other`;
   - **Build Command**: `python3 build.py` (или оставьте пустым, если заливаете уже собранный);
   - **Output Directory**: `.` (текущая папка);
4. Нажмите **Deploy**. Сайт получит бесплатный SSL-сертификат и быстрый CDN по всему миру.

---

### Вариант 3: Собственный VPS / VDS (Nginx)

Если вы разворачиваете проект на собственном Linux-сервере (Ubuntu/Debian), достаточно установить Nginx:

1. Скопируйте файлы проекта в каталог `/var/www/rodoslovnaya`:
   ```bash
   rsync -avz --exclude '.git' ./ user@your-server:/var/www/rodoslovnaya/
   ```

2. Пример конфигурации Nginx (`/etc/nginx/sites-available/rodoslovnaya`):
   ```nginx
   server {
       listen 80;
       server_name genealogy.yourdomain.ru;

       root /var/www/rodoslovnaya;
       index index.html;

       charset utf-8;

       location / {
           try_files $uri $uri/ /index.html;
       }

       # Кэширование тяжелых оцифрованных сканов и PDF
       location ~* \.(png|jpg|jpeg|pdf|ged)$ {
           expires 30d;
           add_header Cache-Control "public, no-transform";
       }

       # Сжатие gzip
       gzip on;
       gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
   }
   ```
3. Активируйте сайт и перезапустите Nginx:
   ```bash
   sudo ln -s /etc/nginx/sites-available/rodoslovnaya /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```

---

### Вариант 4: Docker-контейнер

Для максимальной изоляции можно использовать лёгкий образ Nginx на Alpine Linux.

Создайте файл `Dockerfile`:
```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

Сборка и запуск:
```bash
docker build -t genealogy-tree .
docker run -d -p 8080:80 --name genealogy genealogy-tree
```
Древо станет доступно на `http://localhost:8080`.
