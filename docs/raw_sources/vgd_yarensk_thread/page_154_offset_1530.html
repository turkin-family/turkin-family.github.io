Глеб Горбовский

ЗЫРЯНЕ

Моей бабке А.А. Сухановой

Издревле мы, из рани,
древляне, ведуны,
дремучие зыряне,
на воду шептуны.
Голубоглазый воздух
над нашей головой.
Из мёда мы, из воска,
из ягоды живой.
С кислинкою, с грустинкой,
с куделью бороды,
с прозрачной паутинкой,
летящей вдаль мечты…
Из нежити, из драни,
из стыни и огня —
зоряне, северяне,
зелёная родня!
…Не оттого ль, однако,
как бред во мне, как бес,
сидит занозой тяга —
в глушь вековую, в лес?
Из рвани — не в дворяне,
с топориком — в рассвет!
Таёжные цыгане,
мы есть и как бы — нет…
Порхают наши дети,
как пчёлы без цветов,
пока не ткнутся в сети
прелестных городов.
Из сини мы, из рани,
крестьяне, рыбари,
лесные соборяне,
хранители зари!

Метрические книги Оквадской Введенской церкви есть в архиве Республики Коми только с 1857 года (за ранние годы отсутствуют, последующие годы - с некоторыми пропусками); в Архангельском архиве за отдельные года 18 века и несколько метрик, начиная с 1864 года.
Ревизские сказки по крестьянам Яренского уезда за 1858 г. не сохранились (или пока не обнаружены в архивах).
