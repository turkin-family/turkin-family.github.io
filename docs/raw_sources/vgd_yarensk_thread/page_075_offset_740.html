Глеб Горбовский

ЗЫРЯНЕ

Моей бабке А.А. Сухановой

Издревле мы, из рани,
древляне, ведуны,
дремучие зыряне,
на воду шептуны.
Голубоглазый воздух
над нашей головой.
Из мёда мы, из воска,
из ягоды живой.
С кислинкою, с грустинкой,
с куделью бороды,
с прозрачной паутинкой,
летящей вдаль мечты…
Из нежити, из драни,
из стыни и огня —
зоряне, северяне,
зелёная родня!
…Не оттого ль, однако,
как бред во мне, как бес,
сидит занозой тяга —
в глушь вековую, в лес?
Из рвани — не в дворяне,
с топориком — в рассвет!
Таёжные цыгане,
мы есть и как бы — нет…
Порхают наши дети,
как пчёлы без цветов,
пока не ткнутся в сети
прелестных городов.
Из сини мы, из рани,
крестьяне, рыбари,
лесные соборяне,
хранители зари!

Завершается работа над очередной книгой проекта "Крестьянское родословие". На сей раз книга будет о жителях села Серегово. В ней будут представлены выписки из ревизских сказок, исповедных ведомостей, метрических книг с 17 века по 1923 год. Наиболее распространенные фамилии, начиная с первых найденных метрических записей, - Башлыков, Буткин, Ешкилев, Кондырев, Некучаев, Немчинов, Обросов, Павлов, Перемотин, Поляков, Политов, Странев, Швецов, Шергин, Шидьюсов и др. Наряду с выписками из документов Сереговской Успенской церкви, в книге будут представлены метрические выписки об уроженцах села Серегово из метрических книг усть-вымских церквей, церквей Пермской губернии. Надеюсь, будут интересны списки работников Сереговского солеваренного завода за отдельные годы с 1860 по 1916 гг. Обращаюсь к тем, кто считает Серегово родиной своих предков, своей малой Родиной, с предложением принять участие в подготовке книги, а именно, в сборе фотографий уроженцев села, рожденных до 1923 года. Поднимите, пожалуйста, старые семейные альбомы, поспрашивайте своих пожилых родственников и тогда фотографии ваших предков будут опубликованы в книге.
