# Боковые семьи Туркиных по 1-й и 2-й ревизиям (1719–1748 гг.)

> **Архивные источники**: Российский государственный архив древних актов (РГАДА). Фонд 350, опись 2, дела 4210, 4211 (1-я ревизия 1719–1720 гг.), дело 4216 (2-я ревизия 1748 г.), доп. ревизии 1721–1727 гг.
> **Всего сохранено**: 86 персоналий в 34 домохозяйствах по 7 волостям Яренского уезда.
> **Машиночитаемые базы**: [](file:///home/slava/Documents/Родословная/data/collateral_turkins_1719_1748.json) и единый реестр [](file:///home/slava/Documents/Родословная/data/collateral_turkins.json).

Данный документ представляет систематизированный свод всех боковых семей и представителей старинного рода Туркиных по Яренскому уезду, выявленных в архивных делах 1-й и 2-й подушных ревизий, не входящих в прямую родословную пробанда. Это позволяет сохранить полный историко-генеалогический контекст Яренского уезда для будущих исследований.
